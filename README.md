# Neural Net Playground

> Watch a small neural network learn in real time.

**▶ Live demo: https://darkoes.github.io/neural-net-playground/**

## Features

- Multilayer perceptron, backpropagation and Adam written from scratch in vanilla JS (no ML libraries)`n- 4 datasets (spiral, XOR, circle, blobs), configurable layers, activation, learning rate and noise`n- Live decision boundary, loss curve, accuracy and weight visualization; click to add your own points

## Notes

Try the spiral with 1 x 4 neurons, then with 3 x 8, and watch the difference.

## Tech

Single `index.html` file. Vanilla HTML, CSS and JavaScript, no dependencies, no build step. Hosted on GitHub Pages.

Run locally: open `index.html` in a browser.
